## 📌 Professional Overview

Experienced **Senior Full-Stack Developer & Systems Architect** specialized in delivering high-volume web platforms, telecommunications billing systems, FinTech payment integrations, and community infrastructure software. Proven track record of architecting distributed web applications from ground up, deploying high-throughput network integrations with **MikroTik RouterOS APIs**, and engineering conversational mobile banking applications with **Android Native Kotlin** and **Firebase**.

- 🌐 **Full-Stack Engineering**: Production enterprise applications powered by **Next.js**, **React**, **Node.js**, **TypeScript**, and **PostgreSQL**.
- 📶 **Telecom & Network Automation**: Creator of **GrameenWiFi ISP Management**, automating broadband provisioning, client queues, and MikroTik router APIs.
- 💳 **FinTech & Conversational Payments**: Architect of **PayChat**, integrating P2P biometric transactions into real-time encrypted messaging.
- 🏛️ **Civic & Public Sector Systems**: Builder of **Smart Union**, digitizing public administration workflows and citizen verification documents.
